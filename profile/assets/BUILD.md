# Profile artwork

The SVGs are generated by `assets/src/build.py` in
[Tejas's profile repository](https://github.com/Tejascodex001/tejascodex001).
They embed their fonts and use native SVG animation without JavaScript or remote
requests. Each animated image has a still version selected by the README for
reduced-motion preferences. Local font licenses are included.

The PNG files in `brand/` are the RTensorLabs and FLAME logo marks.
